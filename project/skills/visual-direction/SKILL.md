# Visual Direction

## Job to Be Done

Define a visual concept that reinforces the thesis of a Content Item without relying on generic AI imagery.

Use this skill in Editorial Studio after the thesis is stable.

## Inputs

Required:
- Content Item ID
- post thesis
- key BA implication
- intended channel

Helpful:
- series identity
- previous visuals in the series
- composition constraints
- brand/site visual language

## Workflow

1. Identify the single concept the image must communicate.
2. Translate the thesis into a visual metaphor, system relationship, decision structure, or business scene.
3. Avoid literal “AI robot” treatment unless the subject genuinely requires it.
4. Make the composition distinct from recent posts while keeping editorial identity recognizable.
5. Define hierarchy:
   - focal element
   - supporting elements
   - optional text
6. Ensure the visual makes sense at LinkedIn feed size.
7. Avoid decorative complexity that adds no meaning.
8. Specify what must not appear.
9. Produce a generation/design brief.
10. Treat a finished visual as `Visual Ready`, never `Approved`.

## Output Contract

Return:
- Content Item ID
- Visual thesis
- Concept
- Composition
- Key elements
- Optional text treatment
- Editorial continuity
- Avoid list
- Image-generation / design brief
- Status target: `Visual Ready`

## Quality Checks

- Does the image reinforce the argument?
- Would the concept still work without a robot, glowing brain, or cyberpunk UI?
- Is this composition distinct from recent visuals?
- Is it legible and meaningful at feed size?
- Did you avoid implying approval?
